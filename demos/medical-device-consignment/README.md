# 의료기기 유통 위탁 재고·사용 내역 관리 데모

> 고객사 보안상 고객사명과 데모 자료는 공개하지 않습니다.

| 항목 | 내용 |
|:--|:--|
| 구분 | 데모 (프리세일즈) |
| 기간 | 2026.03 |
| 역할 | 데모 org 구축 |
| 제품 | Sales Cloud, LWC, Apex, Visualforce |
| 상태 | 데모 구축 완료 (2026.03) |

## 풀려는 문제

의료기기를 병원에 먼저 맡겨 두고(위탁), 실제 수술에 쓴 만큼 정산하는 유통 구조입니다.
어느 병원에 얼마가 나가 있고, 얼마를 썼고, 얼마를 회수해야 하는지를 한 흐름으로 봐야 합니다.

## 프로세스 흐름

![프로세스 흐름](process-flow.png)

빨간 테두리가 흐름의 중심입니다. 사용 내역 입력이 이 레코드에 쓰고, 위탁 명세서가 같은 레코드를 읽습니다.

## 데모 범위

- 출고·사용·회수·잔여 수량을 한 레코드에서 관리하는 물류 오브젝트
- 라인 단위로 수량을 입력하는 LWC 편집기
- 제품 기준으로 영업기회와 가용 수량을 함께 보는 제품 360 화면
- 위탁 명세서 PDF 출력

## 구성의 특징

- 위탁 품목은 영업기회의 수주 품목에서 불러옵니다. 수주 수량은 편집 화면에서 읽기 전용입니다.
- 출고·사용·회수를 입력하면 잔여가 바로 계산됩니다. 잔여는 출고에서 사용과 회수를 뺀 값입니다.
- 위탁 명세서는 같은 레코드의 네 수량을 그대로 읽습니다.

## 결과

| 영역 | 데모에서 보여준 것 | 상태 |
|:--|:--|:--|
| 위탁 현황 | 품목마다 출고·사용·회수·잔여를 한 줄에서 입력하고 확인 | 데모 구축 완료 |
| 정산 근거 | 입력한 수량으로 위탁 명세서 PDF 출력 | 데모 구축 완료 |
| 제품 조회 | 제품 하나를 기준으로 영업기회와 가용 수량을 함께 조회 | 데모 구축 완료 |

## 이 문서에 없는 것

- 고객사명과 거래 병원·제품명을 뺐습니다.
- 소스 코드, 필드 API명, 데모 org 정보를 뺐습니다.
- 데모 이전의 업무 방식은 기록이 없어 적지 않았습니다.
- 실제 화면 캡처 대신 일반 레이블로 다시 그린 도식만 넣었습니다.
